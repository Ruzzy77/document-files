# PDF

- 읽기와 구조 작업에는 `pypdf`, 생성에는 `reportlab`을 기본으로 사용한다.
- 원본은 보존하고 별도 출력에 쓴다. 암호화나 권한 우회는 하지 않는다.
- 입력 가능한 양식은 편집 가능 상태를 유지하고, 명시적으로 요청받았을 때만 평탄화한다. AcroForm을 만들거나 고쳤다면 `/Fields`의 필드 구조와 페이지 `/Annots` 안의 `/Widget` 주석 연결을 보존한다. 필드의 값·상속 관계와 위젯의 표시 상태·appearance를 함께 확인하며, 라디오 그룹에서는 그룹의 선택값과 각 버튼의 선택 상태를 구분한다.
- 완료 전에 출력 PDF를 다시 열어 페이지 수, 요청한 페이지 순서, 메타데이터·양식 필드와 필요한 텍스트를 확인한다.
- 이미지 중심 페이지는 일반 추출 결과를 `partial`로 둔다. 대화형 OpenAI 작업에서 내용 확인이 꼭 필요할 때만 관련 페이지만 이미지로 살펴보고, OCR 추정과 원본 텍스트를 구분한다.
- LibreOffice, macOS PDFKit/Vision과 의무적 전체 페이지 렌더링을 사용하지 않는다. 별도 검사 보고서도 만들지 않는다.
- 필요한 라이브러리나 이미지 기능이 없으면 `runtime_unavailable` 또는 부분 추출 범위를 명시한다.
