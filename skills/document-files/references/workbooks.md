# 스프레드시트

XLSX·CSV의 제작·편집과 셀 값·수식 분석에 적용한다. 열린 Excel 앱을 직접 제어하는 경로가 아니다.

- XLSX는 호스트가 제공하면 `artifact-tool`을 우선하고, 필요한 기능이 없을 때 `openpyxl`을 사용한다.
- CSV는 표준 `csv` 모듈 같은 호스트의 텍스트 처리 기능을 사용한다. 원래 열 구분·인코딩·문자열 값을 보존하며 확인을 위해 XLSX로 변환하지 않는다.
- 저장된 값의 자료형, 수식과 계산 캐시를 구분한다. 실제 계산 엔진을 실행하지 않고 수식 결과를 만들거나 캐시를 최신 결과로 단정하지 않는다.
- 요청 범위 밖의 수식, 주석과 데이터 유효성 검사 설정을 보존한다.
- XLSX는 저장 뒤 다시 열어 요청한 시트, 셀 좌표, 값, 수식, 병합 범위와 주요 형식을 확인한다. CSV는 같은 인코딩과 구분자로 다시 읽어 요청한 행·열과 값을 확인한다.
- 전체 셀을 덤프하지 않고 요청과 관련된 범위를 확인한다.

Google Sheets가 결과물로 요청되면 [Google 문서](google-workspace.md)를 함께 따른다. XLSX 저장만으로 Google Sheets 제작을 완료했다고 하지 않는다.
