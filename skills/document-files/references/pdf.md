# PDF

PDF 제작, 페이지 병합·분할·재배열, 메타데이터와 AcroForm 작업에 적용한다. 본문·구조 추출은 Document Files의 공통 분석 경로를 사용하며, PDF 객체·페이지 조작에는 `pypdf`, 생성에는 `reportlab`을 기본으로 사용한다.

- 암호화나 권한을 우회하지 않는다.
- 입력 가능한 양식은 편집 가능 상태를 유지하고, 명시적으로 요청받았을 때만 평탄화한다.
- AcroForm을 만들거나 고치면 `/Fields` 구조와 페이지 `/Annots`의 `/Widget` 연결을 보존한다. 필드 값·상속 관계와 위젯의 표시 상태·appearance를 함께 확인한다. 라디오 그룹의 선택값과 각 버튼의 선택 상태를 구분한다.
- 출력 PDF를 다시 열어 페이지 수, 요청한 페이지 순서, 메타데이터·양식 필드와 필요한 텍스트를 확인한다.
- 이미지 중심 페이지의 일반 추출 결과는 `partial`로 둔다. 내용 확인에 꼭 필요한 페이지만 가능한 이미지 기능으로 살펴보고, OCR 추정과 원본 텍스트를 구분한다. 이미지 기능이 없으면 미확인 범위를 알린다.
