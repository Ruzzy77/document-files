# 발표 자료

PPTX를 만들거나 슬라이드·표·차트·이미지·발표자 노트를 편집할 때 읽는다.

- 호스트가 제공하면 `artifact-tool`을 우선하고, 필요한 기능이 없을 때 `python-pptx`를 사용한다.
- 기존 자료의 master, layout, 관계와 미디어를 요청 범위 밖에서 바꾸지 않는다.
- 편집 가능한 표·차트·도형이 요청되면 실제 편집 가능한 개체로 만든다. 구현 편의 때문에 이미지로 대체하지 않는다.
- 편집 뒤 PPTX를 다시 열어 슬라이드 수·순서, 요청한 텍스트·표·차트 데이터·노트와 패키지 관계를 확인한다.

Google Slides가 결과물로 요청되면 [Google 문서](google-workspace.md)를 함께 따른다. PPTX 저장만으로 Google Slides 제작을 완료했다고 하지 않는다.
