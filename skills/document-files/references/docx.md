# Word 문서

DOCX를 만들거나 본문·표·스타일·문서 구조를 편집할 때 읽는다. 단순 본문 읽기는 Document Files의 공통 추출 경로를 사용한다.

- `python-docx`를 기본으로 쓰고, 라이브러리가 보존하지 못하는 기능만 OOXML을 직접 수정한다.
- 기존 문서의 요청 범위 밖 스타일, section, 관계와 미디어를 유지한다.
- 변경 추적, 댓글, 내용 컨트롤과 수식이 있으면 해당 구조를 보존하는 편집 경로를 선택한다. 변경 수락이나 댓글 제거는 요청받았을 때만 수행하며, 편집 가능한 수식을 이미지로 바꾸지 않는다.
- 생성·편집 뒤 DOCX를 다시 열어 ZIP 패키지와 관계가 유효한지, 요청한 텍스트·표·필드 값이 실제로 들어갔는지 확인한다.

Google Docs가 결과물로 요청되면 [Google 문서](google-workspace.md)를 함께 따른다. DOCX 저장만으로 Google Docs 제작을 완료했다고 하지 않는다.
